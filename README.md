# 🚩 Jantar Mantar Chalo (जंतर मंतर चलो) ✊🚧👮

A 2D top-down satirical browser game based on the Delhi protests. Build your kafila, recruit citizens at chai stalls and metro stations, dodge the Delhi Police cordons, and reach Jantar Mantar to hold the dharna!

---

## 🎮 How to Play

### Online / Local Play
1. Simply clone this repository:
   ```bash
   git clone https://github.com/Durgesh-sharma9/jantar-mantar-chalo.git
   cd jantar-mantar-chalo
   ```
2. Start the local server:
   ```bash
   python server.py
   ```
3. Open in your browser:
   👉 **http://localhost:8085**

---

## 🕹️ Controls
* **Movement:** Point mouse / touch or use `WASD` / `Arrow Keys`
* **Naara / Action:** `Click` / `Spacebar` to chant slogans and push barricades
* **Tear Gas (Police mode):** `Right-Click`
* **Menu:** `Esc`
* **Toggle Sound:** `M`

---

## ✨ Features
* **Bawana Police Station:** Spawn point with temporary detention centre circle.
* **Delhi Landmarks:** Gurudwara Bangla Sahib, Mandir Marg PS, DMRC Metro Stations, Rajiv Chowk CP rings, and Jantar Mantar.
* **Build a Kafila:** Walk into people to grow your protest rally.
* **Facial Recognition Scanner:** Satirical AI face match box over characters.
* **DILLI MAP:** Real-time mini-map in the bottom-right corner.
* **Live Breaking News Ticker:** Satirical updates crawling across the bottom.
